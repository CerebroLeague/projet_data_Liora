🟢 Boucle quotidienne CHAQUE MATIN · ~0 €

Inférence seule — aucun ré-entraînement.

  1. Ingestion des dernières vidéos concurrentes
  2. Rafraîchissement des features de tendance
  3. Génération des idées (LLM + RAG)
  4. Scoring & classement (LightGBM)
  5. Publication du « menu du jour » via l'API
→ Scoring CPU = 0 € · génération serverless = quelques cents/jour

🟠 Boucle de mise à jour HEBDO / MENSUEL · CPU

Déclenchée à la demande ou sur dérive.

  1. Ré-entraînement du scoring sur nouvelles perfs (LightGBM, CPU)
  2. Ré-indexation du corpus RAG (nouveaux docs)
  3. Évaluation vs benchmark
  4. Versionnage du nouveau modèle / index
→ Pas de GPU : réentraînement CPU + ré-indexation ≈ gratuit
